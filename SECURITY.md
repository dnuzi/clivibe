# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within clivibe, please report it privately:

- Open a private security advisory on GitHub under the **Security** tab.
- Or email: `danuz.dev@gmail.com`

Please provide details regarding the environment, steps to reproduce, and any relevant logs. We will acknowledge receipt within 48 hours and work on a prompt resolution.
